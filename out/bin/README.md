# Ejecutar Sessions

Desde la raíz del proyecto: `./build.ps1 -Deploy`. Esta carpeta recibirá el ejecutable, las DLL de Qt y sus plugins.

Los paquetes portables completos se descargan en [Releases](https://github.com/valgaba/sessions/releases). Extrae todo el ZIP y ejecuta `sessions.exe` dentro de `sessions_1_0_0/`.
